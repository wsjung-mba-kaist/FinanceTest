# 금융 전문가 직접 검토와 개선 계획

검토일: 2026-09-14. 대상은 은행·증권·운용·정책 실무자의 개인 훈련이다. 개선 담당자가 각 역할의 관점에서 판단에 필요한 정보와 실제 코드·화면을 대조하고 개선한다. 이번 적용 범위는 레고랜드·LDI의 자금·담보·만기 표시와 공통 후속 처리 안내다.

## 판단 기준

위기 대응 화면은 “누구의 자금인가 → 현재 사용할 수 있는가 → 얼마를 언제 지급해야 하는가 → 누가 어떤 조건으로 실행하는가 → 그 시점에 무엇을 알고 있었는가”를 읽을 수 있어야 한다. 자산 총액·약정액·추정치를 현금과 같은 의미로 보여 주면, 훈련자가 잘못된 전제에서 대안을 선택할 수 있다.

코드의 계산식과 장부 소유자를 먼저 확인하고, 역사 경로의 진행 상태에서 화면을 점검했다. 재현되는 오해는 UI와 설명을 수정하고, 금융 수치·재생·표시의 일관성을 검증했다. 실제 참가자의 성과 향상을 측정했다는 의미는 아니다.

## 계산과 표시의 한계

- 증권사의 현금 부족 추정은 **첫 만기 자체매입만** 비교한다. CP·콜 상환, 미납 마진콜, 추가 조달, 향후 차환 성공률 변화는 제외한다. 0이라고 전체 결제가 가능하다는 의미는 아니다.
- 만기 배열에 개별 만기일·통화·결제 마감 원장은 없다. UI에서 임의의 달력 날짜나 전체 지급 부족액을 만들어 내지 않는다.
- LDI 풀의 담보 현금은 풀 내부 콜 충당용이다. 스킴의 직접 보유 길트는 매각 또는 현물 이전이 필요하며, 스킴 현금도 승인·송금·운용사 반영 전에는 풀의 자금이 아니다.
- LDI 매각 지시의 예정 날짜는 시나리오 처리 시점이다. 예를 들어 T1 지시의 9월 27일 17:30 BST 처리를 11:00 운용사 마감 이전 입금으로 해석할 수 없다. 영업일 결제 달력을 새로 계산하거나 실제 결제 확정을 보증하지 않는다.
- 수치 효과·점수·선택 ID·저장 형식을 바꾸지 않았다. 새 스킴 현금 지표는 상황 판단용이며 기존 복기의 핵심 비교 세 항목을 늘리지 않는다.
- 이번 단계에서 두 시나리오의 모든 사건·선택지에 정보 공개 시각을 적용한 것은 아니다.

## 검증

- 신규 자동 검증 8개: 현금과 약정의 분리, 첫 만기 자체매입 부족액의 계산 범위, 실제 차환 처리 후 만기 이동과 JSON 재생, LDI 자금 소유자와 기관별 도움말, 후속 지시의 정렬·날짜·미래 결과 제외, 모바일 핵심 정보.
- 전체 테스트: 84개 파일, 1,327개 통과·기존 건너뛰기 8개. TypeScript·ESLint·프로덕션 빌드 통과. 기존 500kB 초과 번들 경고는 남아 있다.
- Chromium 1440px 데스크톱·390px 모바일: LDI T0, 매각 지시가 있는 T1, 레고랜드 위기 진행 T2의 실제 화면 시점까지 확인. 가로 넘침과 바깥 문서의 불필요한 세로 넘침 없음.
- LDI 매각 지시 후 실제 새로고침에서도 자금 현황과 후속 지시가 동일하게 복원됨. 페이지 오류 0건.

## 금융적 검토 근거

영란은행의 사후 설명은 연기금의 재정 상태가 개선되어도 LDI 풀에 추가 자금을 동원하는 데 시간이 걸렸고, 다수 투자자의 자금을 모으는 풀에서 그 문제가 특히 컸다고 설명한다. 이를 바탕으로 스킴 자금·풀 담보와 실제 납입 시점을 구별해야 한다고 판단했다. 코드상 금액과 구체적인 실행 절차는 해당 훈련 모델의 값이다. [Bank of England, Sarah Breeden, 7 November 2022](https://www.bankofengland.co.uk/speech/2022/november/sarah-breeden-speech-at-isda-aimi-boe-on-nbfi-and-leverage).

영란은행의 9월 28일 발표는 시장 기능 회복을 위한 임시 장기 국채 매입 조치다. 이 발표를 개별 연기금의 현금 입금으로 해석해서는 안 된다는 검토 기준을 후속 정책·실행 조건 점검에 적용한다. [Bank of England, 28 September 2022](https://www.bankofengland.co.uk/news/2022/september/bank-of-england-announces-gilt-market-operation).

레고랜드 만기 명칭과 LDI 유동자산 산식 수정의 직접 근거는 현재 프로젝트의 [기관별 지표](../src/metrics/byInstitution.ts)와 [증권사 처리 함수](../src/engine/fx/securities.ts)다. 새로운 법규상 한도나 당시 개별 금융회사의 결제 원장을 검증한 것으로 표시하지 않는다.
