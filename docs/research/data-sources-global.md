# 시계열 데이터 소스 및 조회 방법 (글로벌)

한국 데이터는 [data-sources-korea.md](./data-sources-korea.md)를 본다. 이 문서는 미국·글로벌 시계열을
**1차 출처에서 직접 받아 확인하는 방법**과, 접근이 막히는 계열의 해소 경로를 기록한다.

## 1. FRED — 등록 없이 받을 수 있는 것

세인트루이스 연준 FRED의 그래프 CSV 엔드포인트는 키 없이 호출된다.

```
https://fred.stlouisfed.org/graph/fredgraph.csv?id={SERIES_ID}
```

여러 계열을 한 번에 요청하면 **주기(daily / daily-close)별로 묶인 ZIP**이 돌아온다.

```
https://fred.stlouisfed.org/graph/fredgraph.csv?id=DGS2,DGS10,DGS30,TEDRATE,VIXCLS
```

자주 쓰는 계열:

| 계열 | 내용 | 비고 |
|---|---|---|
| `DGS2` · `DGS10` · `DGS30` | 미 국채 2·10·30년 불변만기 수익률(일별) | 연준 H.15 |
| `TEDRATE` | TED 스프레드 | 2022년 중단(LIBOR 폐지) |
| `VIXCLS` | VIX 종가 | Cboe |
| `DBAA` · `DAAA` | 무디스 Baa·Aaa 회사채 수익률(일별) | **전 기간 제공** |
| `DCPN30` · `DCPN90` | 비금융 CP 30·90일 | |
| `DFF` · `DPCREDIT` | 실효 연방기금금리 · 재할인창구 1차 신용금리 | |
| `WALCL` · `WLCFLPCL` | 연준 대차대조표 · 재할인창구 잔액(주별) | H.4.1 |

확인 예(본 프로젝트에서 실제로 사용):

- 2008-09-09 종가 — 2년 2.23% · 10년 3.62% · 30년 4.20% · TED 1.19% · VIX 25.47
- 2008-09-12 — 2.23 / 3.74 / 4.32 · TED 1.36 · VIX 25.66 (리먼 직전 금요일)
- 2020-02-28 — Baa 3.51% · Aaa 2.70% · 10년 1.13%
- 2020-03-23 — Baa 5.07% · Aaa 3.57% · 10년 0.76%

## 2. FRED에서 막히는 것 — ICE BofA 지수

`BAMLC0A0CM`(IG OAS), `BAMLH0A0HYM2`(HY OAS) 등 **ICE BofA 계열은 익명 다운로드에서 최근 3년만
반환된다.** `cosd`·`coed`·`nd` 파라미터를 붙여도 창이 열리지 않는다 — 같은 요청이 `DGS10`은 1962년부터 주고,
`cosd`/`coed`를 바꿔도 **바이트 단위로 동일한 파일**이 돌아온다. 다운로드 제한이 아니라 **ICE 라이선스 제약**임이 확인됐다.
DGS 계열이 같은 요청에서 전 기간을 주는 것과 대비된다.

**해소 경로**: 무료 FRED API 키를 발급받아 `api.stlouisfed.org/fred/series/observations`를 호출하면
전 기간이 나온다. 그 전까지 해당 값은 `[VERIFY]`로 두고, 아래 공개 계열로 **교차 확인**만 한다.

**교차 확인의 한계를 먼저 알 것.** Baa − 10년 국채는 IG OAS의 대용이 아니라 **상한의 목격자**일 뿐이다.
Baa는 IG 중 최저 등급이고 무디스 계열은 듀레이션이 더 길며, 무엇보다 **수익률 차이(yield spread)이지
옵션조정스프레드(OAS)가 아니다**. 결정적으로 이 차이에는 만기 구조가 섞여 들어간다 — 커브가 가파른
국면에서는 장기 회사채 수익률에서 10년 국채를 빼면 **신용위험이 아니라 기간 프리미엄**이 잡혀 값이
부풀고, 반대로 IG OAS가 Aaa − 10년보다 **낮게** 나오는 일도 생긴다(실측: 2021-03-23 IG OAS 92bp 대
Aaa−10y 140bp). 따라서 아래 표는 **자릿수와 방향을 보는 용도**이며, 값의 확정에는 쓸 수 없다:

| 일자 | Baa − 10y | Aaa − 10y | 시나리오의 IG OAS |
|---|---|---|---|
| 2008-09-09 | 335bp | 175bp | 300bp (lehman-2008) |
| 2020-02-28 | 238bp | 157bp | 130bp (covid-2020-fund) |
| 2020-03-23 | 431bp | 281bp | 401bp (covid-2020-fund, 정점) |

2020-03-23의 401bp는 431bp와 자릿수·방향이 맞고, 2020-02-28의 130bp는 Aaa−10y 157bp보다 낮다.
**후자를 근거로 값을 의심하지 말 것** — 위에서 적었듯 커브가 가파르면 그 역전은 정상이다. 두 값 모두
확정하려면 FRED API 키로 원 계열을 조회해야 한다.

## 3. 그 밖의 1차 출처

| 대상 | 출처 | 접근 |
|---|---|---|
| 미국 상장기업 공시 | SEC EDGAR | `https://www.sec.gov/Archives/edgar/data/{CIK}/...` — 10-Q·10-K·8-K 원문이 그대로 열린다 |
| 파산·정리 | FDIC 보도자료, 파산조사관 보고서 | 리먼은 Valukas Report, SVB는 Fed·GAO·FDIC OIG 리뷰 |
| 중앙은행 조치 | Fed 보도자료·H.4.1, BoE 분기보고서 | |
| 국제 기준·사후 검토 | BIS/BCBS, FSB, CGFS, IMF | FSB *Holistic Review of the March Market Turmoil* (2020)이 2020년 3월의 표준 참조 |
| 개별 종목 일별 종가 | 거래소·시세 이력 | 무료 CSV 엔드포인트는 대개 JS 챌린지로 막힌다 — 값과 날짜를 함께 명시한 보도·학술 인용을 쓰고 `[VERIFY]`를 유지 |

## 4. 원칙

- **종가와 장중가를 구분한다.** 시나리오 초기값과 티커 종착점은 항상 *종가*를 쓴다. 장중 고가를
  종가처럼 인용하는 오류가 반복된다(2022-10-25 원/달러, 1997-12-23은 종가가 맞다).
- **지수 이름을 확인한다.** 널리 인용되는 수치가 다른 지수의 것일 수 있다. 2023-03-09의 −7.7%는
  KRE(지역은행 ETF)가 아니라 KBW 나스닥 은행지수(BKX)의 낙폭이고, KRE 자체는 −8.1%였다.
- **닫을 수 없으면 닫는 방법을 적는다.** `[VERIFY]`는 "확인 못 함"이 아니라 "이 문서를 보면
  해소된다"까지 적어야 다음 사람이 이어받을 수 있다.
