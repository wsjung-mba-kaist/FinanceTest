## 의사결정 지점
1. **달러 조달 경로** — 현물 매입(→ 환율 급등) / 외환스왑(→ 스왑레이트 급락) / 한은 통화스와프 입찰(3/31~)
2. **원화 유동성 확보 순서** — CP·RP 매도 → CP 발행 급증 → 채권 매도
3. **헤지 축소 여부** — 델타헤지 증거금 폭증
4. **당국 창구 활용** — 3월 셋째~넷째 주 '공백기'
