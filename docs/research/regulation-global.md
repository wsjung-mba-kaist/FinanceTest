# 글로벌 규제 프레임워크·스트레스테스트 표준·시장 미시구조 참고값

> 원 출처: 구현 계획서 부록 C-4(규제 프레임워크 현행 조문) + B-4(스트레스테스트 시나리오 표준) + B-5(시장 미시구조 참고값). 게임 계산기 파라미터·변수 보정의 근거.
> 한국 규제는 [regulation-korea.md](./regulation-korea.md) 참조.

## 1. 규제 프레임워크 현행 조문 (부록 C-4)

### LCR(Liquidity Coverage Ratio) — Basel Framework LCR20~40
- 최소 100%, 30일 스트레스 기간

#### 유출률(run-off rate)
| 부채 유형 | 유출률 |
|---|---|
| 안정 소매예금 | 기본 5%; 추가 예금보험 요건·관할 승인 충족 시 3% |
| 비안정 소매예금 | 10%+ |
| 중소기업 예금 | 소매 준용 |
| 운영성 예금(operational deposits) | 25%(보험분 5%) |
| 비금융기업·국가·중앙은행·PSE(공공기관) | 40%(전액 보험 시 20%) |
| **기타 법인(은행·증권·보험)** | **100%** |
| 담보조달 — L1/중앙은행 | 0% |
| 담보조달 — 2A | 15% |
| 담보조달 — 2B RMBS·국내 국가/PSE | 25% |
| 담보조달 — 기타 2B | 50% |
| 담보조달 — 기타 | 100% |

#### HQLA(High-Quality Liquid Assets) 헤어컷·상한
| 등급 | 헤어컷 | 상한 |
|---|---|---|
| L1 | 0% | 상한 없음 |
| 2A | 15% | L2 합계 ≤40% |
| 2B RMBS | 25% | 2B 합계 ≤15% |
| 2B 회사채·주식 | 50% | 2B 합계 ≤15% |

※ 계산기 기본값은 **BCBS 텍스트 3%/10%** 사용(아키텍처 초안의 5%/10%는 국내 규정 변형으로 별도 프리셋)

### NSFR(Net Stable Funding Ratio) — NSF20.2
- ≥100% 상시, 1년 기준

### 자본 — RBC20.1
| 구성 | 수준 |
|---|---|
| CET1 / T1 / 총자본 최소 | 4.5% / 6% / 8% |
| CCB | 2.5% |
| CCyB | 0~2.5% |
| G-SIB 버퍼 | 1.0 / 1.5 / 2.0 / 2.5 / 3.5% |
| 레버리지비율 | 3%(G-SIB 버퍼 = HLA의 50%) |

### IRRBB(Interest Rate Risk in the Banking Book) — d368/SRP31
- EVE(Economic Value of Equity) 6개 시나리오: 평행 상·하, 스티프닝, 플래트닝, 단기 상·하
- NII 2개 시나리오
- 이상치(outlier) 기준: ΔEVE > Tier1의 15%
- USD 충격 200/300/150bp [2차]
- **d578(2024.7)로 2026.1.1부터 재보정 — 현행 값 재확인 필요**

### CFP(Contingency Funding Plan) — BCBS 144 원칙 11, ¶110~117
- 책임 라인·발동·에스컬레이션
- 다양하고 즉시 가용한 조치(금액·리드타임 추정)
- 스트레스테스트(일중 포함) 연계
- 기관·시장 시나리오
- 위기팀·연락처·대체자
- 감독당국·중앙은행 접촉 시점 결정권
- 시장·직원·고객·채권자·커스터디 커뮤니케이션 계획
- 중앙은행 창구·담보 요건 반영
- 미국: SR 10-6(2023.8 개정), 2023.7.28 인터에이전시 부록(창구 운영 준비·주기적 테스트 거래)

### 미국 2023 이후 규제 동향
| 항목 | 내용 | 상태 |
|---|---|---|
| 장기채무(LTD, Long-Term Debt) 제안 | 2023.8.29(Cat II~IV, 6% RWA / 3.5% 총자산 / 2.5% 레버리지 노출 중 최대) | 2026.6 S&R 보고서에 미최종화 → 계류 중으로 표기 |
| Basel III 엔드게임 | 2026.3.19 3건 재제안(의견 6/18 마감; 대형은행 AFS 미실현손익 자본 반영) | 재제안 |
| eSLR 수정 | 2025.11.25(2026.4.1 시행) | 시행 |
| CBLR(Community Bank Leverage Ratio) | 9→8%(2026.4.23) | 시행 |

### 런 대응 실무 순서 (BCBS 144·SR 10-6·2023 사후평가)
1. T0: CFP 발동·위기팀·일중 현금흐름 보고
2. 담보 차입 우선(FHLB; 연준 대출 전 FHLB 리엔 후순위화 필요)
3. 재할인창구(사전 예치·테스트 거래; CAMELS 강등 시 2차 신용)
4. BTFP형(액면 담보)
5. 증권 매각(AFS는 AOCI 실현, HTM은 tainting)
6. 증자/사모 예금/합병(미확정 발표는 런 촉발, 확정 컨소시엄 예금은 ~5주)
7. 커뮤니케이션(감독당국 조기, 예금자 일관)
8. 정리(최소비용 원칙, P&A 4유형, 브릿지뱅크, DINB, 시스템리스크 예외)

## 3. 시장 미시구조 참고값 (부록 B-5)

### Basel III 표준 헤어컷 (CRE22.49) [원문 파싱 실패, 텍스트 기준]
| 담보 | 헤어컷 |
|---|---|
| 국채 AAA~AA | 0.5 / 2 / 4%(≤1y / 1~5y / >5y) |
| 기타 발행자 AAA~AA | 1 / 3 / 4 / 6 / 12% |
| A~BBB | 2 / 4 / 6 / 12 / 20% |
| 주요지수 주식·금 | 20% |
| 기타 상장주식 | 30% |
| FX 불일치 | 8% |

### 시장 관행
- 미국 트라이파티 레포(tri-party repo) 헤어컷 ~2%, 비청산 양자 국채 레포 다수 0%(NY Fed 2025)
- IG 회사채 5~10%, 주식 15~25%(CGFS 36)

### 증거금 제도
- UMR(Uncleared Margin Rules) Phase 6(2022.9.1): AANA ≥ €8bn/$8bn, IM 임계 €50m, ISDA SIMM
- LCH SwapClear IM $199bn(+16.5% q/q) vs CME +38%, JSCC +45%, Eurex +61%(2020.1Q)

### SEC MMF 개혁 2023
- 게이트 폐지
- DLA(Daily Liquid Assets) 10→25%, WLA(Weekly Liquid Assets) 30→50%
- 기관 프라임 일일 순환매 >5% 시 의무 유동성 수수료(1bp 미만 면제, 산정 불가 시 1%), 재량 수수료 ≤2%

### ETF
- LQD −5.35%(2020.3); 구성 채권 40%가 하루 1~5회 거래되는 동안 ETF는 수천 회

## 미확인 항목 (구현 시 재검증)
- IRRBB USD 충격 200/300/150bp [2차]; d578 재보정 이후 2026.1.1 현행 값 (계획서 정확성 리뷰 항목: "IRRBB 2026 재보정 충격값")
- 미국 LTD 규칙 상태(2026.6 S&R 보고서 기준 미최종화 → 계류 중) (계획서 정확성 리뷰 항목: "미국 LTD 규칙 상태")
- Basel III 표준 헤어컷(CRE22.49) 원문 파싱 실패 — 텍스트 기준 값
- EBA 2025 주택가격 하락 규모 [규모 미확인]
