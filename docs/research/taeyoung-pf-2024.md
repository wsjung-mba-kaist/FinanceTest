## 정확성 검증 결과 (2026-09) — 법령 원문 접근 경로와 정정

### 국가법령정보센터 Open API로 전문을 받는다

law.go.kr 웹 UI는 JS 프레임이라 스크래핑이 되지 않지만, **Open API는 인증키 자리에 `test`를 넣으면
법령·행정규칙 전문(본문·부칙·별표 포함)을 XML로 반환한다.**

```
https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&MST=257389&type=XML      # 법률
https://www.law.go.kr/DRF/lawService.do?OC=test&target=admrul&ID=2100000276094&type=XML  # 행정규칙(고시)
```

별표는 본문 XML에 인라인되지 않고 HWP/HWPX 첨부로 따로 온다 —
`https://www.law.go.kr/LSW/flDownload.do?flSeq={번호}`. HWPX는 zip이므로
`Contents/section0.xml`에서 태그를 벗기면 본문이 그대로 나온다.

### 이 경로로 닫힌 것과 정정된 것

| 항목 | 결과 |
|---|---|
| 기촉법 부칙 | **제2조(유효기간) ① "이 법은 이 법 시행일부터 3년이 되는 날까지 효력을 가진다."** ② 유효기간 중 소집통보하면 관리절차 종료·중단까지 적용. 제정이유가 직전 법의 만료일을 2023-10-15로 명시하므로 같은 계산(시행일 + 3년 − 1일)으로 **2026-12-25** 만료 |
| 은행 대손충당금 최저적립률 | **별표가 아니라 제29조제1항제1호 본문**에 있다. 그리고 "정상 0.85% 이상, **다만 한국표준산업분류상 건설업(F)·도매및소매업(G)·숙박및음식점업(H)·부동산및임대업(L)은 0.9% 이상**" — 건설·부동산 차주에는 0.85%가 아니라 **0.9%** 다. 고정·회수의문·추정손실에는 기촉법·채무자회생법 제180조제2항 우선변제자산 단서(10%·25%·50%)가 붙는다 |
| 은행업감독규정 [별표 3] | 정식 명칭은 **「자산건전성 분류기준」**. "자산건전성 분류업무 처리기준"은 금감원 해설서 제목이고 감독규정·시행세칙에 그런 별표는 없다(시행세칙 별표 3은 바젤Ⅲ 위험가중자산 산출기준) |
| "유의 = 고정"의 직접 문언 | 2024년 공개문서에는 **없다**. 같은 대응표가 **상호금융업감독규정 [별표 1의2]**(고시 제2026-23호, 2026-06-17)와 **상호저축은행업감독규정 [별표7-1]**(제2026-1호, 개정 2025-11-05)에 뒤늦게 성문화됐다: "'양호'는 '정상'으로, '보통'은 '요주의'로, **'유의'는 '고정' 이하로**, '부실우려'는 … 회수예상가액 부분은 '고정', 초과 부분은 '회수의문'". 개정 전 3단계 문안은 "'악화우려'는 '고정이하'"였다. **은행업감독규정에는 지금도 "사업성"이라는 단어가 없다** |
