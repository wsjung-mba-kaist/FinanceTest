# 1997 외환위기(IMF 위기) (korea-imf-1997)

> 원 출처: 구현 계획서 부록 A-4(해외자료 보완 포함).
> 원 요청 대비 수정: 종금사 10개 인가취소는 1998.1.30 명단 발표 → 2.17 처분 · 1997.12.23 환율 1,962원은 종가, 1,995원은 장중.

## 역할 / 기관
- 플레이어 역할: 재정경제원(재경원)/한국은행(한은) 정책담당
- 대안 역할: 시중은행 자금부
- 등장 기관: 재경원, 한은, IMF(International Monetary Fund), IBRD, ADB, 종합금융사(종금사), 제일은행·서울은행, 예금보험공사(예보), 금융감독위원회(금감위, 1998.4.1 출범), 감사원, 무디스(Moody's), 뉴욕 외채협상 13개 국제은행, 뉴브리지(Newbridge), 국가기록원, KDI, CRS, Korea Herald

## 의사결정 지점
1. **환율방어 vs 변동 허용** — 방어로 가용보유액 39억까지 소진
2. **종금사 폐쇄 시점** — 늦은 조치 → 롤오버 거부 가속
3. **예금 전액보장** — 런 차단 vs 도덕적 해이·공적자금 168.7조
4. **은행 자금부 롤오버 실패 시** — 한은 외화지원(LIBOR+1,000bp) → 정부보증 전환
5. **부실은행 퇴출 vs 국유화·매각** — 5개 은행 P&A(6/29) vs 제일·서울 출자 후 매각
