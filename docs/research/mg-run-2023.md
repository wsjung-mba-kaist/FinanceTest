# 2023 새마을금고 예금인출 사태 (mg-run-2023)

> 원 출처: 구현 계획서 부록 A-5.
> 원 요청 대비 수정: 새마을금고 "5월말 259조→6월말 251조"는 부정확(2022말 251.4조 → 2023.6.29 259.6조).

## 역할 / 기관
- 플레이어 역할: 새마을금고중앙회 자금담당
- 대안 역할: 범정부 대응단 / 지역금고 이사장
- 등장 기관: 새마을금고중앙회, 남양주동부새마을금고·화도금고, 행정안전부(행안부), 기획재정부(기재부), 금융위원회(금융위), 금융감독원(금감원), 한국은행(한은), 예금보험공사(예보), 5대 은행 + 산업은행·기업은행(RP 매입), 감사원

## 의사결정 지점
1. **부실금고 공시 방식·타이밍** — 사전 유동성 확보 후 공시 vs 즉시 공시
2. **지역금고 이사장** — 창구 현금 확충·중앙회 긴급자금 요청
3. **중앙회 조달 순서** — 예탁금 상환 vs 채권 매각 1.6조(시장 충격) vs 은행 RP 6조; 당시 한은 직접지원 불가(2024.8 이후 RP 대상기관)
4. **정부 커뮤니케이션** — 전액 지급 약속 + 이자 원복 재예치 + 장차관 예금 퍼포먼스 → 도덕적 해이 트레이드오프
5. **감독체계** — 행안부 유지 vs 금융위 이관
