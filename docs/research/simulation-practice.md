## 2. 검증된 설계 원칙 6가지
1. 현지 보정된 그럴듯한 시나리오 + 의도적 정보 공백·불확실성
2. 역할 안에서 '토론'이 아닌 '행동'
3. 시간 압축과 우선순위를 강제하는 인젝트
4. 분석 도구가 아닌 의사결정 프레임워크 검증
5. 구조화된 디브리핑 + 문서화된 교훈 + 주기적 반복
6. 즉각적 결과 피드백
