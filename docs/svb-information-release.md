# SVB 전문가 훈련: 정보 공개 시점 검토

은행·증권·운용·정책 실무자의 개인 훈련에서, 판단 시점 이후의 사건이나 선택 해설을 먼저 읽어 답을 추론하는 문제를 줄인다. 이번 적용 범위는 SVB 시나리오의 35개 이벤트, 결정·대화 본문, 전문가 모드의 해설·영향 표시, 피드·이전 구간·로그의 정보 조회다.

## 공개 시각과 자료 근거

`EventInformation.knownAt`은 화면에 표시할 수 있는 가장 이른 시각이며 명시적 시간대가 있는 ISO 문자열이다. 실제 도착은 기존 `atTick`·무작위 도착 지연·분기 조건을 함께 만족해야 한다. 13:10 보고를 시간 단위로 진행하는 훈련에 넣으면, 13:00에는 숨기고 다음 14:00 틱에서 읽게 된다. 이 방식은 분 단위 실시간 재현을 뜻하지 않는다.

`basis: public`은 공개 발표, `basis: reconstructed`는 훈련용으로 재구성한 보고다. 현재 SVB에서는 BTFP·시스템 위험 예외 발표만 공개 자료로 분류한다. 나머지 이벤트는 역사적 자료를 참고했더라도 정확한 내부 연락 시각까지 검증한 것이 아니므로 재구성으로 표시한다. 특히 월요일 수치는 해당 장전 시각의 실제 관측 가격으로 제공하지 않는다.

BTFP 발표는 연준 원문에 **2023년 3월 12일 6:15 p.m. EDT**로 명시돼 있다. 코드 기준은 `2023-03-12T18:15:00-04:00`, UTC 22:15다. [Federal Reserve, March 12 release](https://www.federalreserve.gov/newsevents/pressreleases/monetary20230312a.htm)

SVB 자금 조달·예금 유출의 역사적 맥락은 기존 시나리오 출처와 [연준 SVB 검토 보고서](https://www.federalreserve.gov/publications/files/svb-review-20230428.pdf)를 참고한다. 사후 보고서의 발행일과 그 안에 기록된 사건의 발생·인지 시각은 다르다. 사후 자료로 내부 보고를 재구성할 수는 있지만, 그 보고서 자체를 당시 이용 가능한 문서로 제공하지 않는다. 전문가 플레이에서 전체 출처·학습 자료를 종료 후로 미루는 기존 제한도 유지한다.

## 저술·자동 검증 규칙

- SVB 모든 이벤트 ID가 공개 시각 목록에 정확히 포함되어야 한다.
- 틱 시각은 구간 시작과 일치하고 순서대로 증가해야 한다. 시간대가 없거나 구간이 끝난 뒤에만 읽을 수 있는 자료는 검증 오류다.
- 자료의 공개 시각과 기존 도착 일정 중 늦은 조건을 적용한다. 화면 공개를 늦추더라도 이벤트 효과가 먼저 실행될 수 있으면 저술 검증에서 오류로 처리한다.
- `informationEmbargoes`는 BTFP 명칭이 공개 전 구간 제목·결정·대화·이벤트 본문에 들어가면 검증 오류로 처리한다. 이는 명시한 용어에 대한 회귀 방지이며 모든 미래 사실의 의미를 판별하는 검사가 아니다.
- 종료 후 해설과 내부 효과·보정 설명은 플레이 본문 검사에서 구별한다. 신규 콘텐츠는 자동 검사 외에도 사람이 시점과 표현을 검토해야 한다.
- 메타데이터를 아직 저술하지 않은 다른 시나리오는 기존 표시 동작을 유지한다.

## 검증

공개 직전·직후, 무작위 도착과의 결합, EDT 변환, 불완전한 시각 거부, BTFP 조기 저술 거부, 이전 구간 조회·JSON 재생, 전문가 모드의 설정 우회·영향 화살표를 자동 검사한다. [엔진 회귀 테스트](../tests/engine/informationRelease.test.ts), [화면 회귀 테스트](../tests/ui/informationRelease.test.tsx).

검증 결과:

- 전체 회귀 테스트 1,319개 통과, 기존 건너뛰기 8개. 추가한 공개 시점·전문가 화면 테스트 17개도 최종 수정 후 통과했다.
- TypeScript·ESLint·프로덕션 빌드 통과. 기존 500kB 초과 번들 경고는 남아 있다.
- Chromium 1440px 데스크톱: 전문가 브리핑, 즉시 해설 설정에서 선택 확정, 13:10 메모의 공개 전·후, 시간순 피드 구분선, 이전 구간 조회, 일요일 공개 발표·21:00 ET 표시, 월요일 모의 시세 안내를 확인했다.
- 실제 새로고침 후 전문가 모드 T4 / tick 2와 공개된 메모가 복원됐다. 390px 모바일 피드에서도 메모를 읽을 수 있고 가로 넘침이 없다.
- 모바일 상단 KPI에서 변화량·추이 그래프가 현재 값을 밀어내던 문제를 수정했다. 변화량을 다음 줄로 내려 현금 `$5.5B`, 현재 구간 유출 `$9.7B`, 생존 일수 `0.2일` 등 핵심 값 전체가 표시되는지 확인했다.
- 플레이 화면의 바깥 문서는 뷰포트 높이를 유지하고 각 열이 내부 스크롤한다. 브라우저 페이지 오류는 0건이다.

## 남은 범위와 다음 전문가 검토

수치 효과·점수·선택 ID·저장 형식은 이번 검토에서 변경하지 않았다. 시장 경로와 결제 실행은 기존의 압축된 훈련 모델이며, 실제 장중 거래·송금 원장을 재현하거나 당시 모든 정보의 가용성을 보증하지 않는다. 시나리오 이름에서 역사적 사건을 이미 아는 한계도 있다. 이번 제한은 정상적인 전문가 플레이 흐름을 대상으로 하며 개발자 도구나 별도 학습 경로 전체에 대한 접근 통제는 아니다.

다른 12개 시나리오의 모든 본문을 시점별로 검토한 것은 아니다. 개선 담당자가 직접 금융 실무자의 판단 흐름으로 다음 항목을 점검하고 레고랜드·LDI로 확대한다.

1. 현재 시각과 보고 작성 시각이 구별되고, 늦은 보고가 먼저 노출되지 않는지 확인한다.
2. 공개 발표·훈련 재구성·모의 시세가 구별되며 미확인 사실을 판단 기록에 남길 수 있는지 검토한다.
3. 현금·미인출 한도·익일 반영 예정 한도·마감 기록의 의미를 대조한다.
4. 해설 없이 선택할 때 실행 조건이 충분히 제공되고, 종료 후 자신의 가정·재검토 조건과 비교할 수 있는지 검토한다.
5. 다음 구간·새로고침 후에도 이미 받은 보고와 판단 기록이 보존되는지 검증한다.

레고랜드·LDI의 현금·담보·만기 표시와 후속 처리 시점 개선은 [금융 전문가 직접 검토](./financial-expert-review.md)에 반영했다. 두 시나리오의 전체 정보 공개 시각 검토는 별도 후속 작업으로 남아 있다. 외부 참가자 평가를 기다리지 않고 위 기준으로 분석·수정·검증한다.
