## 2. 역할·기관 프로필

### 2.1 권한 한계
- **직접 실행**: 매입확약 이행·만기 연장 협상·(계약 위반인) 불이행, 조달 채널 선택(은행 크레딧라인·RP·콜·CP·증권금융·정책 프로그램 신청), 보유 채권 매각, 익스포저 공시 수준, 비용 절감·자산 매각 착수, 후순위채 콜옵션.
- **상위 승인(게임에서는 즉시)**: 신규 매입확약 재개, 자회사 매각 완료, 익스포저 한도 공시.
- **사용 불가**: 한국은행 RP 입찰(대상기관 아님 — `bok_rp_counterparty` 플래그 없음), 시행 전 정책 창구(증권금융 10/26 이전, 프로그램 11/24 이전), 인출·결제 지연.

### 2.2 합성 선언
한빛증권 = 2022년 중형 증권사(자기자본 1조원 내외)의 합성 기관. 익스포저/자기자본 47%는 한신평 2022.3 중형 평균[kis-pf-2022-03], 만기 사다리는 업계 만기(금감원 20.2조; 10월 6.2~6.7조·11월 10.7조)[fss-pf-2022, press-abcp-maturity-2022-10] 비율로 스케일한 CAL 값. 나머지 대차대조표 항목은 STYLIZED. 실제와의 차이는 `briefing.simplificationNotes`와 §7.4에 명시. 외생 사건(부도·금리·스프레드·정책)은 실제 기록 그대로이며 플레이어 결정에 불변.

### 2.5 초기 지표
- NCR = (9,000 − 5,250) / 1,500 = **250%** (권고 100 / 요구 50 / 명령 0)
- 유동성비율(게임 단순화) = (1,800 + 1,500 + 2,160) / (1,200×0.05 + 1,000 + 3,500) = **120%** — 라벨 "유동성비율(게임 단순화)"; 실제 규제 산식(1·3개월 유동자산/유동부채)과 다르며 한빛은 현행 규제 대상(종투사·발행사)이 아님
- 차환 만기 도래액(30일) = 1,200 · 차환 성공률 95% · 매입확약/자기자본 47% · 자사 CP 4.4%
- 자체매입 1,000(위험값 100%) → NCR −67%p, 위험값 32% → −21%p (핵심 교육 수치)

## 4. 턴별

옵션표 범례 — H = 역사(historical), T = 함정(trap). 매 턴 D1 "차환 실패분 처리"는 공통 3옵션(A 이행 / B 만기 연장 협상 / C 불이행[T]) + 턴 특수 옵션이며 `shared.ts`의 `rolloverDecision`으로 생성된다. 외생 시계열은 `calibration.md` §6.

### 4.0 틱 구조·인터럽트·대화 (L2)

**T3(10/21)과 T5(11/1)가 틱 턴**이다 — 차환 마감 시각까지 발행이 되느냐가 그날의 전부인 두 날이며, 단기금융시장 하루를 09:00 발행 조건 확인 / 11:00 오전 청약 / 14:00 오후 청약 / 15:30 마감의 네 구간으로 나눈다. 나머지 턴은 단일 틱이며 종전과 동일하다. 전체 근거는 `calibration.md` §13~14.

- CP·전단채 슬라이스는 개장 시점 잔액에 투영되므로 variance 0에서 합계가 `cpRollStep` 단일 호출과 정확히 일치한다(테스트가 1e-9로 단언). 콜차입 정산은 `entryEffects`(개장 시점), 결제 점검은 마지막 틱(마감 집계)에 둔다.
- **D1(차환 실패분 처리)은 마지막 틱에만 열린다** — 마감 집계가 나와야 미달 금액이 확정되기 때문이다.
- 진입 앵커가 **전 영업일 종가**로 바뀌면서 당일 종가가 마감 시각에야 보이게 되었다(사후정보 하루 감소). 마감 시세 기사 `t3-news-aa`도 `atTick: 3`.
- 인터럽트는 `scoreWeight: 0.5`, `defaultOptionId` = 역사 선택이므로 무응답 플레이가 역사 경로로 수렴한다. **대사는 전부 공개 기록 기반 재구성이며 녹취가 아니다.**
- **T4에 `t4-d3` 「증권금융 지원 조건 협의」(3단계 대화)를 신설**했다. `when: { chose: { decision: 't4-d2', option: 't4-d2-a' } }`로 열리고 `required: false`이며, 담보 목록 → `commitReplies('ksfcRequested', [500, 1000, 2000])` → 제출 시점 순으로 주고받아 세 옵션 중 하나로 귀결한다. 효과는 플래그·ΔCI뿐이라 체크포인트에 설계상 영향이 없다.
- `scenario.noise = { runoffSigma: 0.15, runoffCap: 0.3, tickerSigma: 0.01, tickerSigmaBp: 2, eventJitter: 1 }` (가이드 기본값). variance 0에서는 RNG를 당기지 않는다.
