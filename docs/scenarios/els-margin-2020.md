## 2. 역할·기관 프로필

### 2.1 권한 한계
- **직접 실행**: 원화·외화 조달 채널 선택(FX 스왑·현물 외환 매입·은행 원화/외화 크레딧라인·RP 매도·CP 발행·콜차입·정책 창구),
  보유 채권 매각, 증거금 납입, 해외 청산회원·감독당국·언론 커뮤니케이션, 헤지 델타 조정, 자체헤지·백투백 구성 변경.
- **상위 승인(게임에서는 즉시)**: 신규 ELS 발행 중단, 자체헤지 비중 변경, 증안펀드 출자, 외화 유동자산 상시 보유 목표.
- **사용 불가**: 증거금 납입 유예(거래소 규칙), 원화 대납, 개설 전 정책 창구(한국은행 외화자금 입찰은 3/31 이후,
  한국은행 RP 대상기관 편입은 3/26 이후), 결제 지연.

### 2.2 합성 선언
대한투자증권 = 2020년 초 자기자본 4~5조원, 자체헤지 ELS 잔액 10조원 규모의 대형 증권사 합성. 자체헤지 잔액은
업계 45.4조원(2019년 말, 금감원)의 22%이며, 이 비중이 마진콜 규모 환산의 근거다(§7.1). 나머지 대차대조표 항목은
STYLIZED. 외생 사건·시장 데이터·정책 대응은 실제 기록 그대로이며 플레이어 결정에 불변이다.

### 2.5 초기 지표
- NCR = (35,000 − 22,000) / 1,200 = **1,083%** (권고 100 / 요구 50 / 명령 0)
- 유동성비율(게임 단순화) = (12,000 + 8,000 + 22,500) / (16,000×0.02 + 4,000 + 30,000) = **124%** — **원화 지표**이며
  외화 유동자산은 분자에 없다
- 외화 유동자산 **3,000** = 자체헤지 잔액의 3%; 헤지 명목 26,000 기준 지수 −10%이면 하루 소요가 2,600
- 30일 차환 만기 도래액 23,000 · 차환 성공률 98% · 자사 CP 발행금리 1.75%

### 2.6 감독 상태
R0에서 시작. 3/19(T3) 금융감독원 파생결합증권 발행사 외화유동성 일일 점검 개시로 R1. 증거금 미납 시 R3(현장 점검).
보고 불일치(허위 설명·자체 대응 가능 답변 후 실제 부족 확인) 시 R+1.
