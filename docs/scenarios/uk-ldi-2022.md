## 2. 역할·기관 프로필

### 2.1 권한 한계
- 투자정책 안에서 현금 송금·자산 매각·담보 조달·운용사 지시 실행 가능.
- £100M 이상 집행·헤지비율 변경은 투자위원회 결의(정기 위원회 월요일). T0.C 위임 권한 확보 시 CIO가 £500M까지 당일 집행.
- 스폰서 출연은 스폰서 이사회 승인(T0.E 대기약정 시 당일).
- **사용 불가**: 풀드펀드 규정(레버리지 밴드 4.5x·딜링 컷오프 11:00·현금 납입 원칙)의 개별 협상, 영란은행 직접 접근(경매는 운용사 경유), 사후 기준(250bp)의 사전 인지.

### 2.2 합성 선언
노스브리지 = PPF Purple Book 2022의 영국 DB 스킴 우주 자산배분(채권 ≈70%, 주식 ≈20%, 비유동 ≈15%)을 £5bn 규모로 양식화 [STYLIZED]. 풀 레버리지 3x·버퍼 120bp는 계획서 설계값이며 BoE 스태프 페이퍼의 "위기 전 풀드펀드 100~150bp" 범위 안에 있다. 외생 사건(금리 경로·영란은행·TPR)은 실제 기록.

### 2.5 초기 지표
- 담보 여력 = (풀 현금 + 적격 길트) / PV01 = 907 / 7.56 = **120bp**
- LDI 레버리지 = 4,200 / 1,400 = **3.0x** (밴드 상한 4.5x)
- 헤지비율 = 풀 PV01 7.56 / 부채 PV01 9.5 = **80%**
- 펀딩비율 = 4,900 / 5,000 = **98%**
- 유동자산 = 현금 + 직접보유 길트 = 750
- **핵심 교육 수치**: 3x × D18 × 130bp = NAV 손실 70% — 위기 전 버퍼는 3거래일에 소진된다.

### 2.6 감독 상태
TPR 관여 R0. 위기 전 레버리지 LDI에 정량 기준 없음. 강제 축소 발생 시 TPR 통화(R1), 미회신·반복 시 서면 요구(R2).
