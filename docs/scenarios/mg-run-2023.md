## 2. 역할·기관 프로필

### 2.1 권한 한계
- **직접 실행**: 중앙회 자금 운용(상환준비금 지원, 국고채·통안채 매도, 은행권 RP 협의·체결), 정부 커뮤니케이션(브리핑 형식·메시지 수위), 재예치·해지 비용 조치, 부실 우려 금고 처리 원칙(합병·P&A vs 청산) 발표, 특별검사 정보 공개 범위, 대응 체계(범정부 대응단·실무지원단) 구성.
- **"추진"만 가능(법 개정 필요)**: 감독권 이관, 정부 지급보증, 한은 RP 대상기관 편입.
- **사용 불가**: 한국은행 RP·65조 긴급여신(2023년 7월 시점 창구 없음 — 옵션은 보이되 `requires: { flag: 'bok_access' }`로 비활성), 인출 지연·지급 유예(선택 시 즉시 R4).

### 2.2 합성 선언
- 중앙회와 지역금고를 하나의 대차대조표로 합쳤다. 상환준비금 지원·현금 수송 등 중앙회↔금고 거래는 내부 거래(시스템 현금 불변).
- 수치는 2023-06-29 잠정치(관계부처 합동 브리핑 7/6)와 6월 말 확정치(8/31 상반기 실적)를 반올림했다. 현금성자산 77.3조의 구성과 예금 세그먼트는 공개되지 않아 보정값이다.
- 외생 사건(특별점검 발표, 합병 공시, 언론·SNS 확산, 국회 자료 보도)은 실제 일자 그대로 쓴다.

### 2.5 초기 지표
- 상환준비금·가용현금 30.7 / 당일 순인출 0 / 누적 0 / 은행 RP 여력 0.
- 대중 신뢰지수 58 (S1 우려) [CAL]: 연체율 6%대 보도·특별점검 발표 → 합병 공시(−15) 후 S2(43).
- 순자본비율 8.29%(레버리지 지표로 표시), 연체율 6.18%, 예금자보호준비금 2.6.
- 무보험(한도 초과·부실 우려·법인) 비중 ≈ 25% [STYLIZED].
- LCR·CET1·경제적 TCE 등 은행 지표는 계산되지만 KPI로 노출하지 않는다.

### 2.6 감독 상태
행안부 R1 강화 모니터링(특별검사 30개·특별점검 70개 착수). 금융위·금감원·예보는 참여 요청 대기. 한국은행: 직접 지원 불가(RP 대상기관 아님, 65조는 금통위 의결). 감사원 감사 2013년 이후 없음(디브리핑 전용).
