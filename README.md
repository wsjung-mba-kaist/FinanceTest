# 금융위기 대응 시뮬레이션 훈련 플랫폼

리스크·자금·정책 실무자를 위한 **훈련 시뮬레이터**입니다. 실제 위기 기록(연준·FDIC·BoE·금융위·한국은행 등 1차 자료)을 바탕으로 재구성한 시나리오 안에서 시간 순으로 의사결정을 내리고, 그 결과를 정량 지표(LCR, CET1, NCR, 담보 여력, 외환보유액 등)로 확인하며, 실제 역사 경로·전문가 경로와 비교해 학습합니다.

> 본 시뮬레이션은 공개 자료를 바탕으로 교육 목적으로 재구성한 것이며, 수치와 인물의 발언은 단순화·각색되었습니다.

## 실행

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm test         # 계산기·엔진·무결성·자동플레이 테스트
pnpm typecheck && pnpm lint
pnpm build        # dist/ (정적 배포; BASE_PATH=/repo/ 로 GitHub Pages 경로 지정)
```

서버·계정 없이 브라우저에서 동작하며 진행 상황은 `localStorage`에 저장됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `src/engine/` | 결정론적 순수 함수 엔진(턴 진행·결정 적용·지연 효과·게임오버·점수·리플레이·자동플레이), 효과 빌더(`fx/`), 시나리오 무결성 검증기 |
| `src/metrics/` | LCR·NSFR·자본·듀레이션·IRRBB·LDI 마진·PB 익스포저·NCR·외환보유액 적정성 계산기(출처 인용, 기준 테스트) |
| `src/scenarios/` | 시나리오 정의(TS 모듈). `svb-2023/`에 사실 원장(`facts.ts`)·보정 노트(`calibration.md`)·출처 포함 |
| `src/content/` | 지식카드(마크다운)·용어집·출처 서지·읽을거리·트리거 |
| `src/pages/`, `src/components/` | 카탈로그 → 브리핑 → 플레이(3존 대시보드) → 디브리핑, 지식 베이스, 진행 현황, 설정 |
| `docs/research/` | 시나리오별 조사 도시에(검증 수치·타임라인·의사결정 지점·출처·미확인 항목) |
| `docs/authoring-guide.md` | 저작 파이프라인·체크리스트·보정 규칙·스펙 템플릿 |
| `docs/scenarios/` | 시나리오 스펙 문서 |
| `tests/` | 엔진·무결성·자동플레이 테스트와 합성 시나리오 픽스처 |

| 플레이 가능 | `legoland-2022` | 차환의 벽: 레고랜드 이후 (2022 PF-ABCP) | 중형 증권사 CRO | 증권사 |

각 시나리오는 역사 경로(실제 선택 순서)가 체크포인트를 재현하고 전문가 경로가 이를 상회하는지 자동 테스트로 검증됩니다(`src/scenarios/<id>/*.test.ts`). 새 시나리오 저작 절차는 `docs/authoring-guide.md`를 따르며, `pnpm validate`(무결성 린트 + 역사 경로 재현 + 자동플레이)를 통과해야 합니다.

## 화면 구성

플레이 화면은 **상황실(situation room)** 구조입니다. 상단에 시나리오 시계·런 상태·감독 단계, 그 아래 역할별 핵심 숫자 3~4개(유동성 스트립), 본문은 `상황실 | 대시보드 | 피드 전체 | 로그 | 대차대조표` 탭과 상주하는 결정 독으로 나뉩니다. 결정은 선택 + 확정 2클릭이며 5초 안에 되돌릴 수 있고, 확정하면 지표 변화 → 결과 → 시장 반응 → 감독·이사회 반응이 순서대로 재생됩니다.

`?` 또는 `H`로 어디서나 도움 시트를 열 수 있습니다: 이 결정에서 전문가가 보는 것, 지표 설명(왜 중요한가·산식·기준), 관련 카드·프레임워크, 용어집, 지식 베이스 검색, 규정 빠른 참조와 출처.

## 정확성 원칙

- 모든 초기 수치는 `facts.ts`에 출처·기준일·태그(VERIFY/STYLIZED/CAL)로 기록합니다.
- 옵션 효과의 크기는 역사적 유사사례, 문서화된 규칙(Basel 유출률, PCA, 헤어컷, ASC 320) 또는 보정 노트로 정당화합니다.
- 역사 경로는 체크포인트(예: SVB 3/9 유출 $42B ±15%, 마감 잔고 −$958M)를 자동 테스트로 재현합니다.
- 조사 과정에서 확인되지 않은 수치는 `docs/research/*.md`에 [UNVERIFIED]로 남기고 구현 시 재검증합니다.
