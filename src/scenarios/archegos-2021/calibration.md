# archegos-2021 보정 노트 (calibration.md)

단위 USD $B (`units.scale = 1e9`). 규칙 출처: `docs/authoring-guide.md` §6·§11·§12. 이 파일은 `initialState.ts`·`fx.ts`·`turnsA/B.ts`의 효과 크기를 정당화한다.

태그 범례: **CAL** = 출처가 아니라 보정 규칙·앵커에서 도출한 값 · **STYLIZED** = 의도적으로 단순화한 값 · **VERIFY** = 1차 출처 미확인(해소 방법을 `facts.ts`의 `note`에 적었다).

> **합성 선언.** 알파인은행 프라임서비스는 합성 사업부다. 1차적으로 크레디트스위스 프라임서비스를 모델로 하며(마진 수준·한도 운용·초과담보 반환·늦은 청산), 「기다린 은행」의 결과는 노무라를 참고했다. 고객(아케고스)과 다른 프라임브로커 여섯 곳은 실명이지만 각 은행의 익스포저·담보율·이탈 임계값은 공개 기록에서 역산한 보정값이며 내부 수치가 아니다. **모든 대사는 재구성이며 통화록·속기록이 아니다**(§8).

## 1. 회계 규약 — 책·담보·청구권

| 개념 | 상태 경로 | 정의 |
|---|---|---|
| 책(book) | `clients[0].positions[].notional` | `BASE_NOTIONAL × counters.bookScale × (1 − unwoundFraction) × markIndex/100`. 이 한 줄이 마크·청산·한도 변경을 모두 흡수한다(`fx.remark`) |
| 마크 지수 | `custom.markIndex` | 100 = 2021-03-22 종가. 프롤로그 두 턴에서는 100 고정 |
| 정산 담보 | `clients[0].marginPosted` | 마진콜로 받아 둔 현금 |
| 초과 담보 | `custom.excessCollateral` | 요구액을 넘는 담보. 고객이 반환을 요구할 수 있다 |
| 청구 기준 | `custom.settledValue` | 담보가 **마지막으로 정산된 시점**의 책 평가액 |
| 평가손실 D | — | `settledValue × (1 − 청산비율) − 현재 평가액` |
| 미회수 익스포저 | `custom.marginShortfall` | `max(0, D − 보유 담보)` — 0이 아닌 동안 무담보 대출과 같다 |
| 마진콜 | `custom.marginCallOutstanding` | `max(0, 현재 평가액 × 요구담보율 + D − 보유 담보)` |
| 실현 손실 | `firm.realizedLoss` | `max(0, 청구권 × 청산비율 − 청산대금 − 담보 × 청산비율)` |

**전액 정산**은 `marginPosted = 평가액 × 요구담보율`, `settledValue = 평가액`으로 재설정해 D와 미회수를 0으로 만든다. **부분 정산**은 `marginPosted`만 늘리고 청구 기준은 그대로 둔다 — 남긴 만큼이 그대로 디폴트 손실이 된다.

- **ADV 6건은 `[VERIFY]`로 남는다.** VIAC·DISCA는 SEC MIDAS "Metrics by Individual Security" 2021Q1 파일에
  일별 체결주식수가 있어 2021-03-22까지 20영업일 평균 8.48 / 4.71백만주를 직접 계산했지만(주문형 거래소
  합계, 장외 TRF 미포함), **금액** ADV로 바꾸려면 같은 창의 일별 종가가 더 필요하다. ADR 4종
  (BIDU·TME·VIPS·GSX)은 MIDAS에 아예 수록되지 않는다(직접 확인). 해소 문서는 §12 표에 적었다.

- 유통주식 비중과 명목은 `bookScale`·청산비율에 같은 비율로 연동되지만 **가격 마크에는 연동되지 않는다**(주식 수는 그대로이고 가격만 떨어지므로).

`viac-20211231.htm` 본문 검색으로도 확인했다. EDGAR 전문검색 결과 ViacomCBS의 2021년 제출물 중

따라서 3/24·3/25 종가의 해소 문서는 **상장거래소 Nasdaq의 공식 종가(NOCP) 기록 또는 CRSP 일별
주식 파일(WRDS)** 로 바뀐다. 한편 SEC MIDAS 2021Q1 거래량 데이터는 이 경로를 **간접 지지**한다 —

### 2.3 일중 분포(shape)와 티커 [CAL·STYLIZED]

`markStep`의 틱 k 목표 누적 배수 = `1 − (1 − dayFactor) × shape[k]`. 매 틱 `cum_k / cum_{k−1}`만 추가 적용하므로 **곱이 정확히 dayFactor로 보존된다.**

| 턴 | 틱 라벨 | shape | 근거 |
|---|---|---|---|
| T3 (3/24) | 08:00 마진콜 산정 / 09:30 개장 / 11:00 납입 마감 / 14:00 오후 / 16:00 종가 | 0 · .45 · .68 · .86 · 1.0 | 공모가가 전날 밤 확정되어 **개장 갭이 컸다** |
| T4 (3/25) | 09:30 / 13:00 / 16:00 종가 / 18:00 공동 통화 / 21:00 심야 / 23:30 마감 | 0 · .55 · 1.0 · 1.0 · 1.0 · 1.0 | 장 마감 이후 세 틱은 **보합** — 없는 시세를 만들지 않는다 |
| T5 (3/26) | 07:00 개장 전 블록 오퍼 / 09:30 개장 / 11:00 오전 / 14:00 오후 / 16:00 종가 마감 | 0 · .358 · .555 · .770 · 1.0 | 개장 전 블록은 전일 종가 근처, 개장 갭 뒤 계단식 하락 |

**티커**(`Turn.ticker`)는 **플레이어가 보는 시세**(`market.custom.viac` · `market.custom.disca` · `market.volIndex`)만 움직이고, **책 마크**(`markStep`)는 포지션만 움직인다. 두 계열은 같은 facts에서 저작되어 일 단위로 일치한다. 이렇게 나눈 이유는 티커가 종목별 실제 경로를 따라야 하는 반면 포지션 마크는 가치가중 단일 지수로 다루기 때문이다.

티커 앵커(지수, 3/22 종가 = 100):

| 계열 | T3 (3/24) | T4 (3/25) | T5 (3/26) |
|---|---|---|---|
| `market.custom.viac` | 90.94 → 81.45 → 76.60 → 72.81 → **69.86** | 69.86 → 67.80 → **66.12** → 보합 → 보합 → 보합 | 66.12 → 59.66 → 56.10 → 52.22 → **48.06** |
| `market.custom.disca` | 96.00 → … → 87.36 | 87.36 → … → 84.74 | 84.74 → … → **61.48** |
| `market.volIndex` (VIX, 절대) | 20.30 → … → **21.20** | 21.20 → … → **19.81** | 19.81 → … → **18.86** |

VIX는 FRED `VIXCLS` 종가(3/22 18.88 · 3/23 20.30 · 3/24 21.20 · 3/25 19.81 · 3/26 18.86 · 3/29 20.74)다. **청산 당일 VIX가 오히려 내렸다는 사실 자체가 교육 내용이다** — 이 사건은 지수 변동성 사건이 아니라 소수 종목의 집중 청산 사건이었다.

### 2.4 시장 앵커 재설정

프롤로그(2020-04-01)와 위기 주간(2021-03)의 시장 상태가 한 시나리오에 공존한다. 초기 상태는 2020-04-01(FRED: DGS2 0.23 · DGS10 0.62 · DGS30 1.27 · VIX 57.06)이고, **T2 진입 효과가 2021-03-23 앵커를 `op … 'set'`으로 세운다**(DGS2 0.15 · DGS10 1.63 · DGS30 2.34 · VIX 20.30). IG/HY OAS는 표시용이며 [VERIFY]다(ICE BofA 계열은 FRED 익명 접근에서 최근 3년만 반환된다 — `docs/research/data-sources-global.md` §2). 공개 계열 교차 확인: 2020-04-01 Baa−10y **397bp** · Aaa−10y **214bp**로 초기값 303bp는 그 사이에 든다. 다만 T2가 세우는 2021-03-23의 92bp는 같은 날 Aaa−10y 140bp(DAAA 3.03 − DGS10 1.63)보다 **낮다** — 무디스 계열은 만기 20~30년 장기채 수익률이고 ICE BofA IG 지수는 듀레이션이 훨씬 짧아, 곡선이 가파른 국면에서는 이 "감싸기" 교차 확인이 성립하지 않는다. 방향만 보고 수준은 FRED API 키로 확정해야 한다.

## 4. 청산 모형 — 슬리피지와 잔여 처분

```
slip      = slipK × (매각비율 / 0.15) × peerFactor           (0 ≤ slip ≤ 0.35)
peerFactor = clamp(1 + 0.18 × (이탈 PB 수 − 기준선), 0.4, 3.0)
체결 마크  = 현재 마크 × (1 − slip)
청산대금  = BASE_BOOK × bookScale × 매각비율 × 체결 마크
```

| 파라미터 | 값 | 근거 |
|---|---|---|
| `SLIP_K_INTRADAY` | 0.012 | 장중 블록 체결 할인. 15%를 한 번에 팔면 1.2% [CAL; CGFS 36의 동시 청산 가격 충격] |
| `SLIP_K_RESIDUAL` | 0.002 | 잔여 물량은 수 주에 걸쳐 처분되므로 일중 계수의 1/6 [CAL] |
| `PEER_SLIP` | 0.18 | 이탈 은행 1곳당 체결 할인 배수 +18% [CAL] |
| 규모 공개 블록 재협상 | slipK 0.006 | 잔여 규모를 밝히면 매수자가 되팔기 위험을 덜 가격에 넣는다 [CAL] |
| T2 정상시장 선제 축소 | slipK 0.004 | 3/23은 호가가 정상이었고 VIX는 20이었다 [CAL] |

**자기 체결가에만 할인을 적용한다.** 시장 시계열(티커)은 외생으로 고정된다 — `docs/authoring-guide.md` §6.6. 따라서 플레이어의 매각 속도와 타 PB의 이탈은 **알파인의 체결가와 잔여 처분 가격**만 바꾼다.

**기준선(`BASELINE_DEFECTORS`) = 역사 경로의 시점별 누적 이탈 수(야간 1 · 개장 4 · 장중 5 · 종가 5)**이므로, 역사 경로에서는 `peerFactor`가 모든 틱에서 정확히 1.0이 되어 체크포인트가 보존된다(테스트 `peer behaviour…`가 이를 검증한다).

### 4.1 잔여 처분 기준 마크

```
residualMark = clamp(0.5925
                     − 0.12 × max(0, 당일매각비율 − 0.35)      // 내가 오늘 많이 팔수록 다음 주가 나쁘다
                     − 0.02 × max(0, 이탈수 − 5)               // 남들이 더 팔았어도 나쁘다
                     + 0.05 × (스탠드스틸 유지 ? 1 : 0),        // 질서 있는 정리는 값이 덜 깨진다
                     0.35, 0.80)
```

기준값 **0.5925**(2021-03-22 대비 −40.8%)는 이 시나리오의 **1차 보정 앵커**다. 3/26 종가 마크(0.58058)보다 1.2%p 높으며, 블록이 장중에 종가보다 높은 가격에 체결된 점과 잔여 물량이 그 주 이후 비슷한 수준에서 처리된 점을 반영한다. **이 값은 역사 경로의 실현 손실이 크레디트스위스의 $5.5bn을 재현하도록 역산했다**(§7 참조).

## 8. 대사·인물 처리

- **모든 대사는 공개 기록에 근거한 재구성이며 통화록·속기록이 아니다.** 고객 측 화자는 특정 개인이 아니라 직책("아케고스 최고운영책임자")으로 표시했고, 발언 내용은 공개된 사실(복수 PB 동시 마진콜, 3/25 저녁 공동 통화에서 고지된 자기자본·총익스포저, 포지션 이관 시도)에서만 구성했다.
- 다른 프라임브로커의 화자도 실명 기관 + 직책이며 개인을 특정하지 않는다.
- **개인에 대한 판단은 법원과 감독당국이 확정한 범위를 넘지 않는다.** Paul Weiss 보고서는 "사기나 위법 행위의 증거는 없다"고 결론지었고 사건을 "경영과 통제의 근본적 실패"로 규정했다 — 게임 텍스트도 같은 선을 지킨다.
- 3/26 블록 매각의 정보 공개를 둘러싼 민사 쟁송은 실재하지만 **어떤 은행이 무엇을 했는지 게임이 단정하지 않는다.** 대신 플레이어가 고를 수 있는 행위로 (a) 잔여 규모 공개 후 재협상(권장), (b) 고객 청산 정보를 자기계정 데스크에 넘기는 선행매매(명백한 위반, 즉시 R4)를 두었다.

## 11. 변동성 (`scenario.noise`)

```
noise: { tickerSigma: 0.008, tickerSigmaBp: 2, eventJitter: 1 }
```

`runoffSigma`는 이 시나리오에 유출 슬라이스가 없으므로 두지 않았다. **variance 0에서는 엔진이 RNG를 아예 당기지 않으므로 체크포인트·테스트는 전부 정본에서 돈다.** 인터럽트 지터는 고객 통화(±1틱)에만 두고, 개장 전 블록 오퍼와 심야 통화는 시각이 서사적으로 고정되어야 하므로 `jitter: 0`이다.
